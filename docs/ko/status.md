# 프로젝트 상태

[English](../status.md)

상태: **초기 에이전트 스킬 배포가 있는 연구 초안**.

현재 저장소는 공개 설명, 작업 수명주기, 안전 경계, 인공지능용 고밀도 사양, 정적 소개 사이트와 Codex·Claude Code·Gemini CLI용으로 패키징한 0.1.0-draft 에이전트 스킬을 제공합니다. 독립 명령줄 도구, 안정된 스키마 패키지, 검증된 운영 흐름이나 스킬 효과에 대한 통제 증거는 아직 없습니다.

## 현재 초안에서 정한 것

- 구현은 제품 약속이 되기 전에 증거입니다.
- 탐침은 격리하며 핵심 불확실성 하나에 답합니다.
- 승격 전에 사람의 결정이 필요합니다.
- 승인한 동작은 테스트, 계약, 평가 또는 불변조건으로 표현합니다.
- 변경이 배포 가능해지기 전에 독립 검증과 위험에 맞는 배포 게이트가 필요합니다.
- 공개 문서는 검증되지 않은 우월 주장을 피합니다.
- 저장소는 MIT 라이선스로 제공하며, 정확한 조건은 `LICENSE`가 기준입니다.
- 소개 사이트는 GitHub Pages를 사용해 `https://soliestre.github.io/idd/`에 배포합니다.
- 기준 스킬은 `skills/idd/SKILL.md`이며 Codex, Claude Code와 Gemini CLI manifest가 같은 원본을 패키징합니다.

## 열린 결정

- 세 단어로 된 공식 이름은 아직 정하지 않았습니다. 초안 출처는 마지막 단어로 `Defend`와 `Distill`을 모두 사용합니다.
- 안정 버전 전에는 스킬 산출물 모양, trigger 보정과 강제 수준이 바뀔 수 있습니다.

## 아직 필요한 증거

통제된 파일럿은 IDD를 알맞은 기준선과 비교하고 최소한 다음을 기록해야 합니다.

- 질문에서 제품 결정까지 걸린 시간
- 탐침 재작업과 버린 작업
- 밖으로 유출된 결함과 롤백 사건
- 승인된 결정 중 지속 가능한 검사가 적용된 범위
- 독립 검증 실패
- 유지보수자와 검토자의 노력

이 증거가 생기기 전까지 IDD의 장점은 가설입니다.

## 버전 관리

이 문서는 출시 전 작업물입니다. 첫 공개 사양 버전 전에는 용어, 상태와 산출물 모양이 호환되지 않게 바뀔 수 있습니다.
